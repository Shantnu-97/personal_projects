# personal_projects

This repo collects my finance and quantitative projects.

## Option_Pricing_Greeks
Prices a European call and put with Black–Scholes, Monte Carlo simulation and a binomial tree, then studies how fast and how reliably the numerical answers converge to the exact one, including the Greeks (delta, gamma, vega).
**Tools:** Python, NumPy, pandas, Matplotlib.

## Derivative_and_Structured_Products
Four parts: how well discrete delta-hedging replicates an option (and how that depends on rebalancing frequency, volatility and moneyness), building an inflation curve to value inflation-linked pension liabilities, and bootstrapping a credit curve to value a credit default swap.
**Tools:** Python, NumPy, pandas, SciPy, Matplotlib, financepy.

## Real_Estate_Hedonic_Pricing
Estimates a hedonic price model from about 2,700 apartment transactions in Greater Manchester, uses it to compare appraisal values with predicted market values for a 120-asset portfolio, and recommends sell, hold or reposition for each asset.
**Tools:** Python, pandas, scikit-learn, statsmodels, Matplotlib, seaborn.

Open each folder for the full README and code.
